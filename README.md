# Who Lied? — Logic Deduction Puzzle Game

## 概要
4〜6人の証言から矛盾を見つけて嘘つきを特定する演繹パズルゲーム。騎士（常に真実を言う）と嘘つき（常に嘘をつく）が混在する古典的論理パズルを20問収録。

## 機能
- 20問の内蔵パズル（Easy 6問 / Medium 6問 / Hard 8問）
- Easy: 4人・嘘つき1人 / Medium: 5人・嘘つき1〜2人 / Hard: 5〜6人・嘘つき2人
- 各人物カードで「Knight（正直者）」「Liar（嘘つき）」をボタンで指定
- 解答チェック機能（正誤フィードバック）
- ヒント機能（最初の誤り/未割当を指摘）
- 解法ステップ表示（ステップバイステップの推理説明）
- タイマー・ヒント使用数・ストリーク・解決数をlocalStorageで保持

## 使い方
1. 難易度タブ（Easy / Medium / Hard）を選択
2. 各人物の証言を読み、矛盾を探す
3. 各カードの「Knight」または「Liar」ボタンを押して割り当て
4. 「Check Answer」で正誤確認
5. 分からなければ「Hint 💡」または「Show Solution」
